# COLLECTIVE-012 — Shared-Change Horizon
A reported change in one local statement can raise **review urgency** for explicitly linked statements, without making them false or overwriting them.
- Append-only, hash-linked, operator-authored directional and shared-context links; explicit retraction.
- Change checks are operator declarations, **not independently verified by software**. The model never automatically contacts a peer or changes evidence.
- Three hops maximum; max-product pressure prevents double-counting correlated paths. Weights are heuristics **not statistical probabilities**.
- Target separately checked unchanged since the shock blocks the corresponding path. Time-invariant classes are excluded.
- User-authored links may be false; false-link alerts are a critical falsifier. Synthetic tests do not establish real-world accuracy.
- This branch is stacked on draft COLLECTIVE-011 and is not deployed to physical phones.

Run: `node --test test/collective012-dependency.test.mjs`.
See the separately downloadable local development package for the full dashboard and extended benchmark; this first GitHub commit contains the executable propagation kernel and focused test.
